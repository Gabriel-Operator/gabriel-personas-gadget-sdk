# Browser simulator

Start the authenticated bridge using the root quickstart and open its origin.
The browser displays the enrolled persona catalog, capability checks, complete
fixture/live result and revision-bound synthetic review controls.

The simulator uses the same HTTP protocol as Linux and ESP32 clients. Shared
styled form primitives encapsulate the native controls. Credentials remain in
memory and rendering uses text nodes, not untrusted HTML. The UI does not infer
that a synthetic review authorizes a protected live effect.

The implementation ships inside the installed Python package under
`gabriel_gadget/web`. It requires no frontend build or third-party JavaScript.
